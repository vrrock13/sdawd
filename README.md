# 지식의 방주: 라스트 라이브러리 (프로토타입)

`LAST_LIBRARY_GAME_DESIGN.md`를 바탕으로 만든 브라우저 기반 프로토타입입니다.

## 가장 쉽게 열기 (단일 파일 빌드)
```bash
node build.js
```
생성된 `build/last-library.html` 파일을 더블클릭해서 바로 실행할 수 있습니다.
(서버 없이 `file://`로 열기 가능)

## 개발용 실행
```bash
node server.js
```
브라우저에서 `http://localhost:4173` 접속.

> 프리뷰 환경에서 `/preview` 경로로 열어도 동작하도록 라우팅 처리했습니다.

## 구현 포인트
- 검문 데스크형 UI 레이아웃(상단 HUD / 좌측 신문 / 중앙 방문자 / 우측 무전기 / 하단 책상)
- 방문자 요청 + 도서 선택 + 다음 날 결과 로그 코어 루프
- 책 종류별 리스크/보상 반영
- 방문자 사망 시 해당 책 영구 소실
- AI 생성 없이 요청 × 도서 **모든 조합 결과 텍스트를 수작업 테이블로 정의**
  - 각 조합은 기본 결과 + 저확률 변형 결과를 포함

- 퀄리티 연출: 배경 파티클, UI 모션, WebAudio 기반 버튼/환경음
