# 지식의 방주: 라스트 라이브러리 (프로토타입)

`LAST_LIBRARY_GAME_DESIGN.md`를 바탕으로 만든 브라우저 기반 프로토타입입니다.

## 가장 쉽게 열기 (단일 파일 빌드)
```bash
node build.js
```
생성된 `build/last-library.html` 파일을 더블클릭해서 바로 실행할 수 있습니다.
(서버 없이 `file://`로 열기 가능)

## 개발용 실행
```bash
node server.js
```
브라우저에서 `http://localhost:4173` 접속.

> 프리뷰 환경에서 `/preview` 경로로 열어도 동작하도록 라우팅 처리했습니다.

## 구현 포인트
- 검문 데스크형 UI 레이아웃(상단 HUD / 좌측 신문 / 중앙 방문자 / 우측 무전기 / 하단 책상)
- 방문자 요청 + 도서 선택 + 다음 날 결과 로그 코어 루프
- 책 종류별 리스크/보상 반영
- 방문자 사망 시 해당 책 영구 소실
- AI 생성 없이 요청 × 도서 **모든 조합 결과 텍스트를 수작업 테이블로 정의**
  - 각 조합은 기본 결과 + 저확률 변형 결과를 포함

- 퀄리티 연출: 배경 파티클, UI 모션, WebAudio 기반 버튼/환경음

- 아트 연출 강화: 모니터 프레임/볼트, 스캔라인, 포스터형 사이드 위젯, 책상 소품, 벽면 그레인 텍스처

- 질문 시스템 확장: 질문 패널에서 플레이어가 질문 종류를 직접 선택 가능
- 방문자 바리에이션 확장: 아키타입 + 역할/상태 조합으로 매일 다른 인물 생성

- 검문 루프 확장: 신분증/요청서/전화/액세서리 대조 질문, 비상 D.D.D. 호출, 오판/적발 통계
- 방문자/서류 가변성 확장: 주민 디렉터리 기반 이름/직업/주소/액세서리 위조 패턴 조합
- HUD 접근성 강화: 온도·연료·식량·허기·위협도에 아이콘을 붙여 즉시 인지 가능
